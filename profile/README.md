## Get the best work out of more than one model.

Sneferu brings independent AI models together to turn a goal into software, research, and working products. One model proposes. Others challenge and improve the work. Tests, real-world results, and human decisions determine what moves forward.

We call that **adversarial convergence**. The point is not more AI conversation. It is a better result, with a record of how it was built.

## One platform. Different kinds of work.

- **Software:** develop the specification, build in the real project, test, review, and repair.
- **Research:** investigate questions, run experiments, challenge claims, and preserve the evidence.
- **Products and businesses:** explore ideas and carry selected concepts into applications and supporting materials.
- **Games:** bring design, code, art, and playtesting into the same production process.

**[Software On Demand](https://sneferu.ai/sod/)** is the application-building service powered by Sneferu. Describe what you need, review the specification, and try the resulting application before accepting delivery.

## Built with Sneferu

| Project | What it does |
| :--- | :--- |
| [ESM-Gateway](https://github.com/sneferu-ai/esm-gateway) | Long-term memory with typed entries, conflict handling, and a history of what changed. |
| [HungerHall](https://github.com/sneferu-ai/hungerhall) | A playable dungeon-crawler prototype built from a single game concept. |

| [Patchline](https://github.com/sneferu-ai/patchline) | API change notices turned into proposed code repairs, with human-controlled merging. |
| [DrawSheet](https://github.com/sneferu-ai/drawsheet) | An offline-first rodeo office for entries, verifiable draws, results, and payouts. |

Start with each project's README for setup, demonstrated capabilities, and known limitations. Check its license before reusing code or assets.
